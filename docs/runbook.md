# Public Showcase Runbook

## Purpose

This is an OSYSTIC public showcase repository containing sanitized, portfolio-safe material only.

## Operating rules

- Keep the repository classified as `public-showcase`.
- Do not add confidential implementation source or client-identifying material.
- Do not add credentials, private URLs, private infrastructure details, contracts, payments, or private conversations.
- Keep claims limited to evidence recorded in the case study and validation documents.
- If a disclosure concern is found, stop publication changes and review the private source/evidence boundary.

## Regeneration source

The public artifact is generated from an approved sanitized bundle maintained in the canonical private delivery repository. The private repository itself must not be linked or exposed here.
